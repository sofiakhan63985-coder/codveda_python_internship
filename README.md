### 🔹 Level 3 – Advanced

The Level 3 projects focus on advanced Python concepts and problem-solving.

#### 1. File Encryption and Decryption

A Python program for encrypting and decrypting text files.

Features:

* File input
* File encryption
* Saving encrypted files
* Decrypting files
* Restoring the original content

**Technology:** Python

#### 2. N-Queens Problem

A Python implementation of the N-Queens problem using backtracking.

The program places N queens on an N × N chessboard so that no two queens can attack each other.

Concepts used:

* 2D arrays
* Backtracking
* Row and column checking
* Diagonal checking
* Constraint solving

**Technology:** Python

## ▶️ How to Run the Projects

### Step 1 – Install Python

Make sure Python is installed on your computer.

Check the installation using:

```bash
python --version
```

### Step 2 – Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### Step 3 – Open the Project

Open the downloaded folder in **VS Code**.

### Step 4 – Run a Python Program

Open the required `.py` file and run:

```bash
python filename.py
```

For example:

```bash
python calculator.py
```

### Step 5 – Install Required Libraries

For projects that require external libraries, install the required packages using:

```bash
pip install -r requirements.txt
```
